Icon-backspace.png, Icon-shift.png, Icon-enter.png, Icon-emoji.png, Icon-globe.png,
Icon-mic.png, Icon-arrow-left.png, and Icon-arrow-right.png are converted from the
default icon set bundled with FUTO's keyboard-theme-editor
(github.com/futo-org/keyboard-theme-editor, www/icons/*.svg), rasterized from SVG
to PNG with no shape changes.

Icon-shift-press.png (solid caps-lock arrow) and Icon-tab.png have no
official FUTO SVG, so they're rasterized from Tabler Icons instead
(vendor/tabler-icons, github.com/shelbeeely/tabler-icons — a fork of
tabler/tabler-icons): Icon-shift-press.png from icons/filled/arrow-big-up.svg,
Icon-tab.png from icons/outline/arrow-bar-to-right.svg, both converted to PNG
with no shape changes.

Note: the app recolors every icon at render time using the theme's foreground
color for that key state (canvas source-in compositing) — only each icon's
alpha-channel shape matters, not any RGB baked into the PNG.
