9 of the 10 Icon-*.png files in this theme are original, procedurally
generated art (scripts/icon_render.py), not derived from FUTO's own
icon SVGs -- each variant renders its own distinct silhouette style
(stroke weight, sharp-vs-round joints, and pixel-grid quantization
where the profile calls for it), so no icon file is shared byte-
identical with any other theme in this repo.

Icon-emoji.png is the one exception: a generic desktop-computer glyph, evoking this variant's real desktop hardware (Tabler has no IBM or Commodore logo to source an exact brand match from);
rasterized from vendor/tabler-icons/icons/outline/device-desktop.svg
(github.com/shelbeeely/tabler-icons, a fork of tabler/tabler-icons)
with the same stroke-weight/joint/pixel-grid restyling as this
variant's other icons, via scripts/icon_render.py's render_svg_icon().

The app recolors every icon at render time using the theme's
foreground color for that key state (canvas source-in compositing)
-- only each icon's alpha-channel shape matters, not any RGB baked
into the PNG.
